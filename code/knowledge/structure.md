# 互动叙事结构

故事流程由 6–16 个节点组成。每个非结局节点必须有 2–4 个真正改变走向的选项，结局节点不再提供选项。

推荐三幕结构：第一幕建立主角、地点、欲望和异常事件；第二幕让主角付出代价、获得线索、发现关系反转；第三幕把选择汇聚到 1 个或 3 个结局。

每个选项都应该有代价或收益：消耗体力、获得物品、改变信任、暴露秘密，不能只是换一种说法。

至少设置 2 个真正的分支点。所有节点必须从起点可达，不能有断链，不能指向更早的节点。

结局分为 good、bad、hidden 三类。隐藏结局可以有属性门槛，但必须在 UI 中显示进入条件。

伏笔要在前两幕埋下，在结局前回收；如果无法回收，就不要在开头强调。
