# EchoQuest Agent Demo 用户测试

## 测试目标

验证用户从发现故事、创建故事、生成、进入工坊到游玩的核心路径。

## 测试环境

- Windows
- Python 3.13.5
- 本地 `server.py`
- Playwright 1.65.2 + Microsoft Edge
- 无真实模型调用：`/api/health` 返回 `ai:false`，验证本地降级链路

## 用户路径与结果

| 编号 | 用户操作 | 期望 | 结果 |
|---|---|---|---|
| U-01 | 打开发现页 | 显示 4 张故事卡和《雾港来信》 | PASS |
| U-02 | 创建故事并生成 | 进入 `#/studio/<id>`，作品写入 localStorage | PASS |
| U-03 | 输入 2 字背景 | 行内错误，不进入生成 | PASS |
| U-04 | 输入含 `<img onerror>` 的背景 | 作为文本显示，不执行脚本 | PASS |
| U-05 | 375×812 移动端打开并游玩 | 无横向滚动，选项可点 | PASS |
| U-06 | 预览模式推进 | 显示预览徽标，不写 autosave | PASS |
| U-07 | 直接打开 `file://` 页面 | 发现页仍可用，无未捕获异常 | PASS |

## 证据

- `results.json`：逐项结果
- `screenshots/discover.png`：发现页截图

## 测试结论

- 7 / 7 个用户路径通过。
- 未发现阻断性缺陷。
- 发现 1 个错误信息脱敏缺陷，已修复并复测通过（详见 `qa/test-execution-report.md`）。
- 页面无未捕获异常，XSS 注入未执行。

## 未覆盖

- 在线 Agent 的真实模型调用与生成质量（避免消耗 API 额度）。
- 跨设备分享、账号登录和服务端作品持久化。
- 大规模并发和移动端真机键盘遮挡。

## 备注

在线 Agent 版本需要服务端配置 API Key；本次用户测试使用本地降级路径，避免消耗真实模型额度。
